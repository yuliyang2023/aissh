# iOS 独立客户端

产品范围已确定：仅做 iOS 原生 App。SSH 连接和 AI 请求全部由 iPhone 发起，日常使用不依赖电脑、桌面程序或本项目的中转服务。工程与安装说明见 [ios/README.md](../ios/README.md)。

## 连接与数据

```text
iPhone 原生客户端 ── SSH ──→ 目标服务器
                 ├─ SSH ──→ 跳板机 ── SSH ──→ 内网服务器（可选）
                 └─ HTTPS → 用户配置的 AI 服务
```

SwiftUI 管理页面和状态，UIKit / SwiftTerm 提供原生终端，Citadel / SwiftNIO 在手机内完成 SSH 认证、主机指纹校验、PTY、窗口调整和 exec。URLSession 直接访问配置的 Chat Completions 兼容 AI 服务，接收流式文本和命令提案。没有嵌入浏览器页面，没有桌面端网关。

密码、OpenSSH 私钥、私钥口令和 AI Key 保存在本机钥匙串；主机目录、对话与告警记录保存在应用私有目录。手机不读取电脑上的 SSH 配置、凭据或 AI CLI。首次连接展示 SHA256 指纹，改变的指纹会阻止连接。

## 手机交互

| 场景 | 已实现的交互 |
| --- | --- |
| 首页 | 底部「会话 / 告警 / 主机 / 设置」；待确认命令在会话页提供独立入口 |
| 会话 | 「AI 对话 / 监控 / 终端」分段切换，保留草稿和终端实例；主机与环境始终可见 |
| 添加主机 | 连接目标 → 身份验证 → 核对配置；最后一步提供已有主机作为跳板的选项 |
| AI 输入 | 多行输入，回车换行，显式点击发送；阅读历史时可暂停跟随新输出 |
| 命令审阅 | 独立弹层显示完整命令、解释、预期效果、风险与目标；简单只读命令确认一次，其余增加核对步骤与主机名输入 |
| 执行结果 | 执行中、退出码成功、退出码失败、状态未知；请求不自动重试 |
| 终端 | 原生 VT/xterm，竖屏和横屏；Esc / Tab / Ctrl+C / 方向键；粘贴前预览并移除尾部换行 |
| 监控 | 前台按需采集或每 15 秒采集；展示时间、过期状态、内存和磁盘数据；阈值告警在本机记录 |
| 告警 | 卡片展示主机、时间与异常；可把告警带入 AI 草稿，由用户点击发送 |
| 离线与后台 | 保留记录，过期审批失效；连接中断后显式重连；可开启设备身份验证解锁 |

主要触摸操作使用至少 44 点高度；界面遵循系统安全区、深浅外观和原生键盘。终端使用等宽字体，可横屏获得更宽的命令区域。

## 命令执行边界

AI 只能生成建议。完整且受支持的工具提案才进入审批；未结束的流、截断数据和多工具请求不成为可执行命令。审批绑定当前会话、连接代次和审阅版本，切后台、断线、重连或提案变化都会使旧确认失效。主机端命令通过独立 SSH exec 通道执行，子 Shell 返回随机完成标记和退出码。未收到完成标记时不宣称成功，也不重发。

远端输出作为不可信文本传给 AI；手机已读取的登录秘密及 AI Key 在请求与记录中替换。无法保证识别服务器输出中的所有未知秘密，用户可以关闭附带终端输出。远端终端控制序列无法读写手机剪贴板。

## 首版范围

支持密码、OpenSSH Ed25519 / RSA 私钥和跳板链；支持同时保留多个会话。AI 可独立于 SSH 连接状态进行对话，但执行命令必须有有效连接。

iOS 后台时间有限：切后台停止 AI 与周期监控，系统给予的后台时间耗尽后关闭 SSH。此版本没有持续后台监测、远程推送、文件传输、SSH Agent、keyboard-interactive 登录、多设备同步或桌面数据迁移。首次配置和后续使用都可以在手机上完成；开发签名安装需要 Xcode 与开发者身份。

## 验证入口

`bash scripts/test-ios.sh` 运行单元、SSH 集成和原生 UI 测试。本地 SSH fixture 只监听回环地址，验证真实协议握手、指纹、PTY 与 exec 返回状态；不执行收到的 Shell 命令，不访问生产服务器。UI 测试使用独立数据与明确标注的演示模式。

此前的 [HTML 交互草图](mobile/interaction-prototype.html) 仅留作设计参考，示例数据不联网。最终实现以 `ios/` 原生工程为准。
